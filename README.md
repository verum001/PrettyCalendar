# pretty calendar

A tiny offline womens calendar for Android, with a kawaii sakura style.

- Hold a date to set a violet lotus and start a cycle. A new date replaces the previous cycle.
- Heart on day 14, pink flower on day 28, counting the selected date as day 1.
- Automatic night theme from 21:00 to 07:00, with gentle animation.
- No ads, accounts or internet connection needed. Your data stays on your phone.

**Android 8.0+ · APK \~362 KB**

Build with Android Studio (JDK 17, SDK 35) or `./gradlew assembleDebug`.\
